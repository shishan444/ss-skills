# 材料事实与结构重建

## 任务

把材料从“原作者怎样写、笔记怎样散落”转换成两层连续认识：先用读者能够直接理解的语言还原现实中发生了什么、目前有哪些基本事实、事情怎样发展，再看清这些内容由什么关系构成。

交付物是一份重建后的内容底稿。它不是原文缩写、原句降重、分类报告、新闻评论或写作策划。对于包含事件的材料，读者应当不用拆解原文修饰语，也不用回看原文，就能回答：

- 事情是什么；
- 基本情况是什么样的；
- 事情怎样发展到当前状态；
- 在这些事实之上，哪些关系、矛盾、观点和信息边界值得看清。

事实层保证读者先有立足点，分析层负责提供关系增量。深度不能替代基本事实，也不由篇幅、栏目数量或术语证明。

## 核心转换

```text
原始呈现
  → 把现实内容与原文措辞、顺序和包装分开
  → 从全文重建最小但足够的核心事实
  → 用白话说清事情是什么
  → 归并基本情况
  → 还原事情发展
  → 找到统领深层内容的核心关系或矛盾
  → 归并散落内容并完成分析
  → 在相关位置保留来源与认识边界
  → 内容底稿
```

这套过程用于内部思考，不要把分类过程、方法说明或核对声明写进交付物。

## 一、先脱离原始呈现

完整阅读全部输入。暂时放下原文标题、句法、段落顺序、材料来源顺序和用户随手记录的先后，把它们视为内容的载体，而不是天然结构。不要以原文的一句话为骨架做删词、调序或同义替换；核心事实可能分散在标题、正文、数据、回应和不同材料中，必须从整体关系重新建立。

在内部辨认真正承载意义的单元，例如：

- 发生了什么或发生了怎样的变化；
- 谁提出了什么判断、解释、感受或诉求；
- 哪些内容是依据、例子、条件、转折或限制；
- 哪些片段在说同一对象，哪些只是表面相邻；
- 多份材料在哪些地方重复、补充、错位或冲突。

同时判断材料是否真的包含一件事的发生、状态变化或发展过程。新闻、事件记录、经营变化和产品进展通常属于事件型材料；纯观点、感受、概念摘录和一两句想法可能不属于。

这些名称只是理解工具，不得自动变成输出栏目。

## 二、先建立事实认识层

事件型材料默认先按以下认知顺序展开。四部分职责不同，不能相互替代。

### 1. 事情是什么

这一部分不是导语摘要，而是对材料所指现实的重新建模。先在内部摆脱原句，判断：如果拿掉作者的修饰、术语和叙述顺序，究竟是哪一方做了什么、什么状态发生了改变，以及哪一项变化、问题、冲突或争议使这些信息构成同一件事。再把分散在全文中的必要联系合成一小段自然白话，让没有读过原文的人一遍就知道“到底发生了什么”。材料没有冲突或争议时，不为增强戏剧性而补造。

重建时使用普通读者熟悉的名词和动作，优先呈现具体行为与真实变化。身份标签、头衔、数量、职位类别和机构表述只有在改变事件性质时才进入概述；否则移到“基本情况”。即使几项身份属性都与事件有关，也不要把它们串成一段履历式长定语，而要先回答这些属性在事件里发挥什么作用，用能够说明该作用的简洁角色表述统领；精确身份再由“基本情况”承接。抽象口号不能代替它实际对应的权限、行为、状态或结果变化。

这里追求的是“最小但足够”：删去不影响第一遍理解的细节，却保留使事件成立的关键关系。核心关系应直接成为概述的主干，不要先复述一个表面事件，再另起一句解释“真正关键是什么”；具体动作应被组织进这条关系，而不是与它前后重复。如果删掉开头的表面概括，后面的解释反而更清楚，说明概述还没有完成重建。

完整事件的概述通常收成一个连贯短段。段内每句话都应增加构成事件的新内容；已经用具体行为呈现了核心关系，就不要再补一句抽象话把同一关系总结一遍。需要第二段才能让人明白本质时，优先回到第一段重写，而不是追加解释。

它不是固定槽位，也没有通用句式；主体、行为、变化、结果或争议应依据材料中的真实关系取舍。表面用词相近的材料，如果参与关系和证据不同，就必须形成不同的核心事实，而不能沿用先前案例的解释。

白话不等于武断。材料只是某个来源的报道、质疑、判断或推测时，把归属自然写进概述；只能说到“被指做了什么”，就不能改写成“已经这样做了”。不要为了说得有力而补出目的、因果或结论，也不要把后面的深度分析提前塞进概述。

完成后暂时不看原文，检查这段话能否让人立刻复述核心现实。如果它仍依赖一长串身份修饰才能成立、只是原句变短，或读者还要读完“基本情况”才知道真正发生了什么，就重新建模。

### 2. 基本情况

把理解事件所必需的事实从原文各处归并起来，包括材料确实提供的主体、身份、时间、地点、行为、关键数据、当前状态和来源。只保留会帮助读者建立事实图景的内容，不逐项填表。

若输入是转载、转述或二手报道，简明保留“当前材料来源 → 原始报道 → 原始报道所依据的信息”这条来源链。来源链是基本情况的一部分；不能省掉中间层级，把报道中的指称直接写成无来源事实。

“事情是什么”给出经过白话重建的全貌，“基本情况”补构成全貌的身份、时间、数量、职位、来源和其他关键事实。后者必须增加信息，不能把前者换句话重写；前者也不能把所有支撑细节抢先堆满。

### 3. 事情的发展

按关键时间、阶段或状态变化说明事情怎样走到现在。优先保留会改变理解的节点、转折和当前停点，而不是把原文每一段重新排列成流水账。

材料没有清楚进程时，不补造时间线。短事件可以把发展压缩为数句；只有一个静态事实时，可以与基本情况合并。

事实认识层不等于外部事实核查。报道、知情人士说法、当事人判断和用户记忆仍保留各自来源，不因被放入“基本情况”就升级为已经独立证实的事实。

## 三、再建立深度分析层

事实已经足够复述后，再找出最能降低理解成本的组织力。它可能是：

- 一件事的关键变化与传导；
- 一个问题及围绕它形成的解释关系；
- 一个核心矛盾及构成它的几股力量；
- 若干主体、观点或材料之间的对应关系；
- 一种认识由观察、依据到判断的形成过程；
- 材料自身呈现出的其他结构。

选择标准不是“最像模板”，而是它能否容纳大部分重要内容，并让每个分析部分知道自己为什么在这里。

“事情是什么—基本情况—事情发展—深度分析”是递进的认知阶段，不是四条并列的分析轴。进入深度分析后，必须有一个主导组织轴；不要再把时间、来源、证据、观点和用途直接摆成同级分析栏目。

同级部分必须是同一个整体下性质一致的分支。证据、来源、条件和不确定性通常应放回它们所支撑或限制的内容附近，而不是另起一套平行报告。

如果材料确实包含多个互不相关的主题，分别重建，不强造一个共同中心。

## 四、完成真正的重组

事实层先归并“发生了什么”，分析层再围绕主骨架处理“这些事实彼此是什么关系”：

- 把原文不同位置谈论同一对象或关系的片段归并；
- 先用自己的话重建事实关系，再决定怎样表达，不把任何原句默认当成概述骨架；
- 合并真正重复的表达，保留会改变理解的差异；
- 把依据放到它支持的主张下面，把限制放到它限制的判断旁边；
- 让事情概述、基本情况和发展过程各自承担不同信息，不重复填充；
- 分析层先呈现核心关系，再安排分支、依据、限制和例子，使层级可见；
- 调整原始顺序，让事实认识顺序和分析理解顺序取代记录顺序；
- 保留有意义的旁支、个人感受和未成熟想法，但明确它们在整体中的位置。

重组后的内容应同时让基本事实和原来散落的关系变得可见。仅仅缩短原文、逐段改写、恢复时间顺序或贴上正确标签，都不自动算深度重组；同样，直接给出漂亮的分析判断但让读者说不清事件本身，也不算完成。

如果原始顺序本身已经是最清楚的内容顺序，可以保留；不要为了证明“处理过”而机械打乱。

## 五、认识边界只做护栏

事实、观点、推测、诉求和来源的差异，只在混淆会改变理解时明确：

- 来源使用事实语气，不等于内容已经被独立核实；
- 主体的解释、判断和感受仍属于该主体；
- 从材料推出但尚未坐实的关系，应自然写明其推断位置；
- 拒绝透露、没有回应或材料缺失，不能自动当作承认、否认或反证；
- 多份材料冲突时，说明分歧落在哪里以及它限制了什么，不替材料裁决。

边界说明应贴近相关内容。事实层交代来源归属，分析层限定推断和解释；除非材料本身就是一场认识性质的争论，否则不要另建完整的“事实／观点／推测”目录。

如果上游交付协议要求明确区分“已验证／据材料推断／尚未确认”，把相应限定放在它所约束的句子附近；不要在正文已经限定之后，再用一组状态栏目重复汇总。若确实必须附交付状态，只用一句紧凑注记，不复述内容。“已逐项核对”“未联网”“调用了某 Skill”等执行过程不是材料内容，不进入底稿。

## 六、按材料类型控制形态

### 事件型材料

信息足以支撑完整事件底稿时，默认使用以下四个可见的阶段主标题，让读者一眼知道自己处在哪个认知阶段：

1. `事情是什么`；
2. `基本情况`；
3. `事情的发展`；
4. `深度分析`。

第四个标题可以写成“深度分析：具体核心关系”，但不能只用一个含义不明的内容标题替代“深度分析”。前三个标题也可以在冒号后补充内容名称，但不得改变认知顺序。

前三层合起来应当足以让读者复述事件；第四层应增加关系认识，而不是再次摘要。完整新闻、多源事件、产品变化和经营变化通常使用这一形态。

### 非事件材料

观点、感受、概念摘录或未成形想法没有真实事件进程时，不硬套“事情发展”。先说清已有内容或核心主张，再重建依据、关系和边界。多组材料中的事件部分与观点部分可以采用不同形态。

### 微型材料

一两句材料通常直接重写成一段清楚表达，最多保留一个真正必要的不确定点。不要把四层认知顺序机械变成四个空标题。若不确定性已经在段落中表达，输出到此结束，不再追加同义的“尚未确认”或“认识边界”。

## 七、交付停在材料本身

默认只整理用户给出的内容。不得因为材料未来可能用于写作，就增加：

- 写作方向、文章切口或选题；
- 推荐表述、标题或文章结构；
- 行动建议、解决方案或产品建议；
- “下一步应当补充什么”的资料清单；
- 外部背景、事实核验结果或材料之外的新论点。

用户材料中原本存在的计划、建议、诉求和待办，应作为材料内容忠实保留；不要把它们扩写成整理者自己的建议。

用户另行要求查证、研究、立意或成文时，先保持本底稿边界，再把新增任务交给相应流程；不要让这些能力反向污染材料重建。

## 输出方式

事件型材料先给经过白话重建的事实入口，再逐层深入；不要用原文导语的缩写或一句抽象分析结论取代“事情是什么”。深度分析内部先用一小段话或一个紧凑关系表达统领关系，随后沿同一个主骨架展开。

信息充分的事件型底稿固定使用前述四个阶段标题；各阶段内部的标题、列表、时间线、引语或连续段落，只在它们能显露真实层级时使用。非事件与微型材料不为形式完整补设标题。

只有存在一个无法贴近局部内容、且会限制全篇理解的新边界时，才在结尾保留一句尚未确定的边界。正文已经逐处限定后，直接结束，不再用“尚未确认”“认识边界”或状态清单重复汇总。

### 细度

- 一两句未成形想法：通常直接重写成一段清楚表达，最多保留一个真正必要的不确定点。
- 短便签：用少量段落或要点呈现已有情况和主关系，不扩写成报告。
- 单篇事件文章：先建立事件事实层，再判断文章内部真正由哪些关系构成；不要沿原文顺序摘要。
- 多份材料：优先按共同对象、问题或关系归并，不逐份摘要；只在关键差异处保留来源。
- 复杂材料：只有新增层级、关系、冲突或边界才值得展开。

如果输出明显长于输入，每一处扩展都必须在揭示关系或澄清边界，不能只是换句话重复。

## 禁止的替代品

- 有许多标题但没有统领关系的栏目堆叠；
- 一上来给出深层判断，却没有说明事情是什么；
- 从标题或导语删掉几个词，仍沿用原句的头衔、修饰和抽象包装；
- 把多个相关身份属性串成长定语，却没有说清它们在事件中的实际作用；
- 先复述表面事件，再用“关键在于”另写一遍真正的核心关系；
- 看到熟悉的主体、行业或关键词，就套用另一个案例的动机、关系或结论；
- 为了白话直接而省掉“谁在说、依据到哪里”的必要限定；
- “事情是什么”和“基本情况”重复，“事情发展”只是原文重排；
- 深度分析重复前三部分，没有新增关系认识；
- 给没有事件进程的材料补造时间线或四个空栏目；
- 按原文顺序压缩后的摘要；
- 按来源逐份复述后再加一个小结；
- 全量事实、观点、推测标签表；
- 正文已经完成限定后，又追加“已验证／推断／未确认”的重复汇总；
- 把材料中的主张升级为已核实事实；
- 为了连贯而补造动机、因果或结论；
- 在底稿后追加写作方向、推荐写法、建议或后续清单；
- 用方法说明、执行声明和自我核对占据交付内容。

## 交付自检

交付前逐项检查：

- 能否用一句话说清这份材料的整体构造，而不只是主题名称；
- 事件型材料的“事情是什么”是否脱离原文句法，用白话说清核心行为、变化以及材料确实存在的关键问题或争议；
- 核心关系是否直接统领概述，而不是在表面摘要之后作为二次解释出现；
- 概述是否已经收成一个连贯短段，没有在具体事实之后再次抽象总结同一关系；
- 概述是否只保留理解事件性质所必需的关系，把不改变性质的身份、数字和职位细节留给基本情况；
- 必须保留的身份信息是否已转化为事件中的功能角色，而不是继续堆成履历式定语；
- 白话化是否保留来源和不确定性，没有把质疑、判断或可能性升级成事实；
- 当前理解是否来自这份材料的实际关系，而不是由相似关键词、领域或既有示例触发固定结论；
- 事件型材料是否继续说清基本情况和发展过程；
- 前三层是否各有职责且没有大段重复，单独阅读能否复述事件；
- 深度分析是否位于事实层之后，并提供了事实层没有的关系增量；
- 深度分析的同级部分是否都直接属于同一个主骨架；
- 原来散落但相关的内容是否已经归并，支撑与限制是否各归其位；
- 如果输出大体沿原文顺序，是否因为原顺序确实最佳，而不是没有重组；
- 是否保留了会改变理解的来源差异、观点位置和不确定性；
- 是否出现材料之外的写作方向、推荐表述、行动建议或补充清单；若有，删除；
- 是否新增了材料不能支持的背景、动机、因果或结论；
- 非事件和微型材料是否避免了机械套用四层结构；
- 读者拿到结果后，是否无需再清理结构噪声。
