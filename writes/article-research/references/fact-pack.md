# 事实底稿契约

事实底稿分为两层：

- **事实主稿**：让下一阶段迅速看清事情怎样形成、各方处在什么位置、哪些变化最值得继续观察。
- **证据附录**：让每个决定性事实可以回到来源，让冲突、口径、受阻与未知保持可审计。

主稿与附录不能彼此全文重复。没有新增事实时，重组的价值应表现为关系更清楚，而不是篇幅更长。

## 一、事实主稿

~~~markdown
# 事实底稿：<事件名称>

## 1. 定事

用一至三段回答：

- 这究竟是一件什么事；
- 它从什么状态走到什么状态；
- 当前已经发生到哪一步，什么尚未发生。

只写确认事实和最重要的止步处，不在开头列研究字段。

## 2. 一张局面图

用最适合本事件的一种形式，把以下内容合在一处：

- 三至七个真正改变事情理解的时间节点；
- 三至七个关键人物及其位置、行动、约束和关系；
- 必要的地域、制度、产业或国际尺度。

可以用时间—人物双栏、关系图或短段落，不强制同时使用多张表。

每个关键事实标记 F 编号与证据编号，例如 F3 [S2][S5]。

## 3. 决定性变化

只保留会改变后续立意的三至七项变化：

### C1 <变化名称>
- 原来：
- 现在：
- 谁的选择、成本、约束、资源或位置改变：
- 落地状态：已经发生 / 已确定但尚未实施 / 可能后果 / 当前未知
- 认识状态与证据：事实 / 来源说法 / 推断 / 冲突 / 未知；[Sx]

## 4. 已知、分歧与止步

### 已建立的关系

只写支撑后续判断的事实链；能引用 F、C 编号时不重复整段事实。

### 分歧与未知

| 问题 | 能确认什么 | 不能确认什么 | 为什么会改变理解 | 建议补证 |

### 止步处

集中说明哪些结果尚未发生、哪些因果不能建立、哪些数字不能混用。

## 5. 交给下一阶段继续看的地方

列出三至七个由事实直接显出的张力或位置变化。只指出“哪里值得看”，不写最终文眼、标题或价值立场。
~~~

## 二、证据附录

证据附录跟随主稿，也可以链接到独立 evidence.jsonl。至少包含：

~~~markdown
## 证据附录

### 事实索引

| F / C 编号 | 最短事实表述 | 认识状态 | 证据编号 | 口径或局限 |

### 来源索引

| 证据编号 | 页面标题 | 发布者 | 日期 | URL | 来源角色 | 使用状态 | 局限 |
~~~

“使用状态”区分：决定性证据 / 背景证据 / 来源说法 / 受阻未采用。

若已有独立证据账本，来源索引只保留主稿实际引用的来源和受阻来源，可链接账本，不必复制所有摘录。

## 三、去重规则

1. 一条事实只在一个主位置完整表述。
2. 后文再次使用时，引用 F 或 C 编号，只补充新的关系或边界。
3. “定事”不复述完整时间线；“局面图”不再复制成单独的人物表；“决定性变化”不把全部法规条款逐项搬入。
4. 分歧与未知只收影响理解和立意的内容，不保存一般性的未来研究愿望。
5. 出处只列一次；证据短摘录放证据账本，不放主稿反复展示。
6. 未增加新事实时，主稿显著长于输入，默认视为尚未收束；先删重复，再考虑是否确有必要保留。

## 四、“势”的落地检查

一条合格变化必须回答：

1. 原来是什么状态；
2. 哪个可确认变化发生；
3. 谁的选择、成本、约束、资源或位置改变；
4. 改变已经落地，还是仅存在于制度文本或推演中；
5. 证据与止步处在哪里。

“行业迎来新时代”“格局被重塑”“底层逻辑变了”若不能补全以上五项，删除或降级。

## 五、最小完整性

事实底稿可以交给 article-plan，当且仅当：

- 开头能让人明白事件从什么状态走到什么状态；
- 决定性时点、人物位置、关系和变化均有处置；
- 数字保留时间、单位、口径与适用范围；
- 因果、推断、相关、分歧和未知没有混写；
- 决定性事实能通过 F / C 编号回到来源；
- 受阻来源没有被当成证据；
- 主稿没有用重复换取表面完整；
- 新搜索不再改变局面，只增加重复背景。

## 六、禁止转换

- “正式公布”不等于“已经实施”。
- “权利被写入制度”不等于“现实能力已经形成”。
- “相关方称”不等于“事实证明”。
- “两件事同期发生”不等于“前者导致后者”。
- “媒体大量转载”不等于“多个独立来源”。
- “栏目都填满了”不等于“事情已经讲清”。
- “使用了势、局、理等词”不等于“形成了中文思维”。
