# 立意池与定稿简章契约

这份契约保留构思所需的证据和边界，但不要求逐格填写研究表。每个候选应该像一则作者可以据此下笔的“立意札记”，读起来先见事情与判断，再见理路与止步处。

## 一、立意札记

~~~markdown
### 立意：<一句自然中文名称>

**眼前之事**
哪项具体事实、变化或矛盾触发了这个立意。

**换到哪里看**
从谁的位置、哪种关系、哪个时间或尺度观察；这个位置让原事件显出什么不同。

**人的入口**
哪类具体读者会从什么钱、工作、机会、风险、身份、选择、未来或熟悉场景进入。

**文眼**
从【具体事情或矛盾】可以看见：【核心判断】。

**意脉**
读者原本所见 → 旧解释的裂缝 → 位置转换 → 关键机制 → 新的现实状态 → 止步处

**根与界**
- 事实根基：决定性事实及来源编号
- 关联性质：因果 / 推断 / 对照 / 结构类比 / 历史参照 / 概念重构
- 反方解释：
- 不能越过的边界：
- 若要写得更强还缺什么证据：

**与其他候选真正不同之处**
新增的是人物位置、关系机制、时间后果还是核心判断；若只是换标题，应合并。
~~~

## 二、候选池停止检查

- 至少从事实内部完成一次“观变—找结—换位”。
- 至少从人的现实处境完成一次“照人”。
- 新候选不再增加人物位置、矛盾、机制、时间后果或文眼时停止。
- 同一文眼的不同开头归为一个候选，不以数量制造丰富。
- 无证据的热点连接移入待补证，不作为正式候选。

## 三、定稿简章

~~~markdown
# 定稿简章

## 文眼

- 一句话文眼：
- 从哪件具体事看见：
- 为什么现在值得说：
- 主要写给处于什么现实位置的人：

## 入题

- 从哪个具体场景、利害、人物处境或认知反差进入：
- 读者眼前通常看见什么：
- 哪个事实使旧解释不够：

## 意脉

1. 起点：读者先看见什么；
2. 转处：哪条事实迫使观察位置改变；
3. 力点：必须说透的关系或机制；
4. 回照：新的理解怎样改变对原事件的看法；
5. 止步：哪些结果尚不能确认。

这五项描述认识的推进，不是规定正文必须写五节。

## 根与界

- 决定性事实及来源编号：
- 反方解释：
- 判断成立的条件：
- 事实、制度文本、实施过程和现实结果如何区分：

## 成文取舍

- 应重点写透：
- 只需交代：
- 留在候选池、不进入本篇：
- 写作中绝不能越过：
~~~

定稿简章只决定“说什么、为什么成立、怎样推进到那里”，不替 article-write 决定具体段落、句式、文气或金句。
