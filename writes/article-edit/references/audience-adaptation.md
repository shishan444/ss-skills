# 对人调声契约

## 一、先看这个人怎样读

画像信息按可靠性从高到低理解：

1. **所关**：阅读目的和正在面对的现实问题；
2. **所知**：已有知识、概念熟悉度和误解位置；
3. **所历**：能够自然识别的工作、生活、公共或时代经验；
4. **所处之境**：媒介、阅读时长、注意力条件和使用场景；
5. **所习之语**：直接或含蓄、口语或书面、克制或有温度，以及共享文化参照；
6. **人口信息**：年龄、性别、学历和地域仅为弱线索。

人口标签不能单独推出前五项。只有标签时，应说明不足、询问关键问题，或采用明确的中性假设。

## 二、从读者距离到表达动作

| 读者距离 | 可以怎样调 | 不能怎样调 |
|---|---|---|
| 知识距离 | 概念先给场景；术语随文解释；补足必要逻辑桥梁 | 删除决定性机制；把准确概念换成错误俗称 |
| 经验距离 | 使用读者熟悉且不承担证据责任的类比 | 虚构真实事件、人物或数字作为例证 |
| 关切距离 | 让原文已有利害更早被看见；过渡回到其现实问题 | 新增迎合性的观点；替读者规定立场 |
| 阅读情境 | 调整句长、段落呼吸、重复和解释密度 | 因手机阅读而压掉完整逻辑 |
| 语言距离 | 调整声口、语气、典故、口语和文化参照 | 用刻板腔调扮演某类人 |

## 三、五个调声旋钮

| 旋钮 | 可调方向 | 意义边界 |
|---|---|---|
| 声口 | 亲近 ↔ 克制；温和解释 ↔ 直接判断 | 不改变作者立场与判断强度 |
| 句气 | 短句分步 ↔ 长句压缩；多停顿 ↔ 连续推演 | 不吞掉主语、因果和条件 |
| 疏密 | 多解释一步 ↔ 压缩共同常识 | 不删除决定性事实和逻辑桥梁 |
| 温度 | 让事实先说话 ↔ 明确表达感受 | 不夸大事实，不替读者表态 |
| 文化距离 | 现代白话 ↔ 文雅点染；中性表达 ↔ 适量网络语 | 不炫技、不过时、不冒犯、不刻板 |

## 六、文化表达检查

每个古语、典故、口语和梗都应满足：

- 与读者共享语境；
- 比现代直说更近、更准或更有节奏；
- 上下文足以自明；
- 删除后事实和理路仍完整；
- 不制造炫技、过时、冒犯或刻板印象。

没有明确收益时，以清楚、自然的现代汉语为准。
