# 故事八卦式科普

## 写作任务

把一个原本抽象的机制、组织结构或思维方法，写成一篇零基础读者愿意听、听得懂、听完能复述整体关系的中文口语稿。

这不是把教材换成几个俏皮说法，也不是借题发表长篇议论。正文的主次固定为：**故事负责吸引人，知识负责建立全貌，观点负责留下余味。**

这里的“全面”是让读者得到一张完整的关系图：谁在其中、各自想做什么、为什么出现问题、机制怎样运转、能够解决什么、又解决不了什么。它不要求列完所有专业细节。

## 事实与叙事边界

- 叙事可以假设，事实不能编造。使用“假设你是……”“不妨把它想成……”等方式明确虚构场景，不把虚构对白写成真实历史。
- 类比只负责帮助理解，不能替代机制本身。写完类比后，要让读者知道现实中的对象、动作和限制分别是什么。
- 不确定的事实、时间、人物和因果不得补写成确定内容。决定性材料不足时，先指出缺口；用户允许合理假设时，显式标明假设。
- 不为故事效果制造错误的善恶二分。证书不等于安全、规则不等于不会被绕过、成功案例不等于普遍规律。
- “伪科普”只表示以故事为外形完成知识导览，不表示可以牺牲准确性；除非用户要求，不在成稿中自称“伪科普”。

## 先选一条简单逻辑

动笔前只选一条能够贯穿全文的逻辑，不叠加多个框架：

- **组织结构**：角色出现 → 各自分工 → 相互依赖 → 权力或信息冲突 → 组织怎样维持运转。
- **机制原理**：目标出现 → 直觉办法 → 现实约束 → 机制形成 → 运行过程 → 代价与漏洞。
- **思维方法**：具体困境 → 常见误判 → 方法介入 → 判断改变 → 适用条件 → 失效边界。

根据题目选择最贴切的一条。逻辑只存在于后台，正文不展示框架名称，不写成“第一步、第二步”的教程。

## 十一段叙事骨架

正文必须严格写成十一段。标题不计入段落；每个由空行分隔的正文块算一段。正文中不再使用小标题、编号或项目符号。

1. **把门踹开**：用一个反常问题、利益冲突或像八卦一样的消息开场，让听众立刻想知道“凭什么”。
2. **人物入场**：交代主角、其他关键角色以及他们各自想得到什么，不先解释术语。
3. **摆出大家都信的说法**：写普通人最自然的直觉、传闻或误解，让读者先站到故事里。
4. **事情开始不对劲**：出现一个直觉解释不了的麻烦、漏洞或利益冲突，故事第一次转向。
5. **试一个最直接的办法**：让角色采取看似合理的方案，并具体写出它为什么诱人。
6. **让办法撞墙**：放慢语速，把真正的现实约束讲清；这是机制能够登场的必要原因。
7. **揭开核心机制**：用最少术语说清机制的基本动作，明确现实对象与故事角色的对应关系。
8. **让机制跑起来**：加快节奏，用动作链、对话或连续后果展示各部分怎样配合，而不是继续下定义。
9. **别急着庆功**：写对手怎样绕过、机制怎样失灵，或者它为解决问题付出了什么代价，使全貌闭合。
10. **作者只站出来一次**：放慢语速，给出一个由前文承重的明确判断。观点只推进一层，不讲人生大道理，不连续输出金句。
11. **回到开场并收口**：用一句有力度、便于口播的回环或反转结束，让读者既记住故事，也记住机制的边界。

十一段是语义动作，不是平均长度。关键转折可以短促，核心机制可以略长；但任何一段都不能只为凑数，也不能把两个语义动作挤成一段。

## 口语与语速

写成一个见过这件事的人正在当面讲，而不是教师照着课件念：

- 多用具体动作、关系和后果，少用抽象名词串联。
- 强烈语气来自冲突和判断，不来自连续感叹号、粗口、网络梗或故作惊讶。
- 快处使用短句、并列动作、追问和迅速转折；慢处使用稍长的句子、停顿和具体解释。让读者仅凭句长和标点就能听出节奏，不标注“加速”“停顿”等舞台指令。
- 可以使用“你以为……”“问题来了”“可事情没这么简单”一类口语连接，但不得每段重复同一种口头禅。
- 专业词第一次出现时立刻用白话解释；能不报术语名称就说清楚的地方，不为显示专业而报术语。
- 故事必须持续推进。知识自然嵌在人物遇到的问题、采取的办法和付出的代价里，不插入一段脱离情境的百科说明。

## 观点的分量

全文只保留一个中心判断，主要落在第十段，也可以在前文留下轻微伏笔。观点应当提炼故事已经展示出的关系，例如“安全不是认出所有坏人，而是限制坏人混进来以后能做多少事”。

不要为了显得有思想而突然升华。删掉观点后如果机制仍然完整，但读者少了一层可迁移的认识，说明分量合适；删掉后故事事实都接不上，说明观点替代了必要解释；删掉后毫无区别，说明观点只是装饰。

## 默认交付

默认输出一个有吸引力但不夸大的标题，以及严格十一段连续正文。除非用户明确要求，不附提纲、段落标签、写作说明、知识点清单或自检报告。

## 写后静默复核

交付前直接修稿，不展示检查过程：

1. 标题之外是否恰好十一段，每段是否承担不同的叙事动作。
2. 零基础读者能否说清角色、目标、问题、机制、作用和边界，而不是只记住类比。
3. 是否始终只有一条简单逻辑，故事是否比术语更靠前。
4. 快慢是否能从句长、停顿和动作密度中听出来，强烈语气是否自然。
5. 是否只有一个主要观点，并且由前文承重，没有说教或连续拔高。
6. 是否混淆事实与假设、把类比当原理，或为戏剧性牺牲准确性。
