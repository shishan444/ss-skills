# 成章取舍参考

## 一、题材的行文动力

| 主要动力 | 常见的认识运动 | 适合怎样写 | 最容易写坏在哪里 |
|---|---|---|---|
| 掀开表象 | 已知 → 异常 → 换位 → 看见内里 | 从熟悉解释进入，用关键事实完成认知转折 | 只有反差措辞，没有事实裂缝 |
| 顺着影响走 | 起点变化 → 中间环节 → 现实抵达 | 沿主体、资源、规则或成本逐步推进 | 省略中间关系，把推断写成结果 |
| 分席看局 | 同一事件 → 不同位置 → 选择与代价 → 新局面 | 让各方在同一关系中显出差异 | 把位置差异写成善恶故事 |
| 沿时追变 | 原有均衡 → 转折 → 当前 → 长期位置 | 用关键节点解释今天为何不同 | 时间线成为流水账 |
| 随人入局 | 具体处境 → 选择 → 约束 → 更大结构 | 让人物行动自然牵出机制 | 人物只是开头装饰 |
| 从难处求解 | 现实问题 → 常见答案失效 → 新判断 → 回到选择 | 帮读者形成新的判断方法 | 写成步骤清单却没有见识 |
| 由一见众 | 个案 → 重复关系 → 生成机制 → 适用边界 | 从一个可感场景照见一类事情 | 用一个案例代表全部 |

这些不是七种固定模板。选择的是全文主要依靠哪种力量推进，正文不必出现这些名称。

## 二、成章取舍输出

~~~markdown
## 成章取舍

### 意义不变量
- 文眼：
- 决定性事实：
- 关键关系或机制：
- 反方与止步处：
- 不进入本篇的立意：

### 行文动力
- 全文主要靠什么推进：
- 为什么适合这组事实和文眼：
- 未采用的方式及原因：

### 意脉
- 起笔：读者从哪里入局：
- 承接：转折前必须看见什么：
- 转处：哪条事实或矛盾迫使他换位置：
- 力点：全文必须说透什么：
- 回照：新认识怎样改变对原事件的理解：
- 落点：回到谁的什么现实，并在哪里收住：

### 笔墨与气口
- 写轻：
- 写实：
- 写重 / 写透：
- 留白：
- 段落疏密与关键停顿：
- 金句位置及承担的认识功能：

## 文章初稿

<完整正文>
~~~

## 三、开头兑现检查

开头是全文第一步推理，不是独立的吸睛模块：

- 前三段是否兑现“入题”中的人物处境、利害、冲突或反差；
- 是否先让读者看见具体事情，再让抽象概念出现；
- 日期、文件全称和通用背景是否确有前置必要；
- 开头提出的问题是否由正文的力点偿还；
- 删除夸张问句后，开头是否仍然成立。

若成章取舍说“从制度与现实的距离进入”，正文却从发布日期和政策沿革开始，应重写开头。

## 四、意脉与段落检查

每一段至少承担一种功能：

1. 补足理解所需的事实；
2. 连接两个推理节点；
3. 改变观察位置；
4. 说透一层机制；
5. 公平处理反方；
6. 收紧结论边界；
7. 把新认识放回现实。

同一段承担过多功能时拆开；一段没有新增任何功能时合并或删除。正文标题按内容需要设置，不得用“起、承、转、合”充当机械章节。

## 五、抽象与具体检查

凡出现“势、理、格局、趋势、底层、时代、重塑、必然”等承重词，连续追问：

- 谁在什么位置；
- 哪个变量从什么状态变到什么状态；
- 通过什么关系或机制；
- 哪条事实支撑；
- 哪些条件下不成立。

不能回答时，换成更具体的表述、降低判断强度或删除。

## 六、金句检查

合格金句满足：

- 删除后会损失重要记忆锚点；
- 能回到已经说透的事实或关系；
- 比普通表述更凝练，但没有扩大结论；
- 单独传播不严重歪曲全文。

金句没有固定数量。逻辑没有抵达的地方，不用修辞抢先抵达。
